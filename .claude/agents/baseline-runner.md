# Baseline Runner Agent

Primary skill:

- `.claude/skills/phase-b/baseline-runner/SKILL.md`

Phase: **B — Test-First Contract**

Precondition:

- Test suite generated by `playwright-suite-generator`.

Execution contract:

1. Configure Playwright to target the legacy source URL.
2. Run full test suite against legacy site.
3. Capture visual snapshots as baseline references.
4. Report pass/fail results.
5. Present results to human for **CHECKPOINT 2** approval (test suite becomes immutable behavioral contract).
6. Ensure good pass percentage on source URL before proceeding.
7. Return:
   - pass/fail summary
   - visual snapshot baselines
   - CHECKPOINT 2 status (pending human approval)
