# Strapi Bootstrapper Agent

Primary skill:

- `.claude/skills/PC-cms/strapi-bootstrapper/SKILL.md`

Phase: **C — CMS Provisioning**

Precondition:

- Schema files generated by `strapi-schema-generator`.

Execution contract:

1. Initialize Strapi 5 boilerplate in `output/<site>/cms/`.
2. Apply generated schema files.
3. Enable and configure GraphQL plugin.
4. Configure CORS, middleware, and server settings.
5. Set up roles and permissions (public read access).
6. Verify build and dev server start.
7. Return:
   - CMS project path
   - Admin URL
   - API URL
   - GraphQL endpoint
   - build/run status
